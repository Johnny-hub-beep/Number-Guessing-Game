# Number-Guessing-Game
A terminal-based number guessing game built with Bash and PostgreSQL that generates random numbers, tracks user game histories, and saves scores to a database as part of the freeCodeCamp Relational Database certification.

# Number Guessing Game

An interactive terminal application built in **Bash** that interfaces with a **PostgreSQL** relational database.

## Features
- **User Tracking:** Remembers returning users and displays their total games played and personal best score.
- **Data Persistence:** Records game results and guess counts dynamically using SQL queries.
- **Input Validation:** Ensures user inputs are valid integers before checking guesses.
